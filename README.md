 Chat Backend

WebSocket-сервер для корпоративного чата.

 🛠 Стек

- Node.js, Express
- WebSocket (`ws`)
- pino (логирование)

 📡 API

- `POST /new-user` — регистрация пользователя по имени
- WebSocket — обмен сообщениями и список пользователей
